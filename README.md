# Waniwani agent (moved)

This repo is archived. The runtime that serves Waniwani website chat now lives in the private `WaniWani-AI/waniwani-agents` repo, under `app/agent`, with its full history.

Waniwani no longer offers a self-hosted agent runtime, so there is no image to pull and no deployment guide here any more.

`@waniwani/agent-adapter` is still published on [npm](https://www.npmjs.com/package/@waniwani/agent-adapter). New versions come from the new repo, tagged `agent-vX.Y.Z`. The `v*` tags in this repo cover releases up to `0.1.0-beta.6`.
