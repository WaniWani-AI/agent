# Waniwani agent (moved)

Development of the runtime that serves Waniwani website chat moved to the private `WaniWani-AI/waniwani-agents` repo, under `app/agent`, with its full history. This repo stays public, but it gets no new commits.

`@waniwani/agent-adapter` is still published on [npm](https://www.npmjs.com/package/@waniwani/agent-adapter). New versions come from the new repo, tagged `agent-vX.Y.Z`. The `v*` tags here cover releases up to `0.1.0-beta.6`.
